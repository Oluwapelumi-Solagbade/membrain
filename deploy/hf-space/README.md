MemBrain (team Cerebro Spark) demo: concern-first brain-health navigation for adults 50–75 in the UAE, with
Gulf-Arabic dictation by our fine-tuned Whisper model. Prototype: clinician-supervised, never diagnoses,
no real names. This demo server is outside the UAE; the real service is designed to run in the UAE.
