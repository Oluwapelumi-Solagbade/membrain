🛡️ Why Play Protect warns

It flags every app installed from outside Google Play by a developer it has not verified. It is not a malware finding.

  • Demo build signed with a development key, not by Google Play
  • Asks for 3 permissions only: internet, microphone, audio settings
  • No contacts, location, camera, SMS or file access
  • All traffic is HTTPS to the MemBrain server
  • A Google Play release (Play App Signing) removes the warning
If Play Protect blocks it outright, tap More details → Install anyway, or send the app for scanning; nothing on the phone needs to be switched off
